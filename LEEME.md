# LAS RETAS

Tres juegos multijugador: carreras, futbolito y peleas. Cada quien puede elegir apodo, color y personaje.

## Juega online

Abre https://las-retas.onrender.com y elige un juego. Usa **INVITAR** para copiar el enlace de tu sala y compártelo con tus compañeros. Todos deben abrir el mismo juego y el mismo nombre de sala para jugar juntos.

El servidor funciona con el plan gratis de Render. Si lleva un rato sin actividad, puede tardar unos segundos en despertar.

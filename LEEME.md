# LAS RETAS

Tres juegos multijugador separados: Carreras, Futbolito y Peleas. Cada persona escoge apodo, color y personaje.

## Para jugar en esta computadora

1. Descarga `las_retas.zip` y elige **Extraer todo**.
2. Dentro de la carpeta extraída, haz doble clic en **ABRIR LAS RETAS.bat**.
3. Se abrirá el menú. Elige un juego, personaliza tu personaje y entra.
4. Deja abierta la ventana negra mientras juegas. Al cerrarla, se apaga el servidor local.

No necesitas escribir comandos ni ejecutar `npm install`. El lanzador usa Node.js si está disponible en la computadora. Si Windows dice que no encuentra Node.js, instala Node.js y vuelve a abrir el archivo.

## Para que entren compañeros desde otros lugares

El enlace `localhost` solo funciona en tu computadora. Para que tus compañeros se conecten desde sus casas, hay que publicar el proyecto en un servicio de hosting. Esta carpeta incluye `render.yaml` para ese paso. Después comparte la dirección pública y el mismo nombre de sala; el botón **INVITAR** copia el enlace de esa sala.
